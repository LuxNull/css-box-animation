# CSS Box Animation

A demonstration of CSS animations using `@keyframes`.

## 🎨 What's inside
- Box movement animation (translate)
- Smooth movement left and right
- Color change animation
- Pure CSS, no JavaScript

## 🛠 Technologies
- HTML5
- CSS3 (Animations, Keyframes)

## 🚀 How to run
Open `index.html` in your browser and watch the animation!

## 📚 What it demonstrates
- Using `@keyframes` to create animations
- The `transform: translate()` property for movement
- The `infinite` and `alternate` parameters for continuous animation
